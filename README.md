# HFEDM-Hypothetical-Five-Layer-Emotion-Dynamics-Model
A mathematical specification for a five-layer emotional dynamics system designed for conversational agents.
對話與任務情境下之情緒動力模型
## 這是甚麼

一個面向對話代理使用的情緒數學模型。它把情緒建模成五層動力系統（氣質錨定 → 對象 sentiments → 長期背景 → 近端反應 → 短期心情 + 主觀疲勞），輸出十一軸狀態（十種情緒 + 主觀心智疲勞），並明確區分情緒模組與記憶模組的所有權邊界。
本倉庫目前以**規格與理論文件**為主，提供可計算的方程、介面契約與工程數學初值，尚未包含完整實作程式碼或人類效度驗證。
## 核心特點

- **五層分工**：L1 情感風格（緩慢）、L2 對象 sentiments、L3 長期背景 \(m\)、L4 近端反應 \(e\)、L5 短期心情 \(x\) + 疲勞 \(f\)。
- **移動限制盒**：長期背景直接限制短期心情的允許區域 \(\mathcal{C}(m)\)，而非只靠衰減。
- **事件與持續輸入分離**：一次性事件跳躍 + 持續來源 + 內部殘留演化。
- **有界人格適應**：僅透過合格經驗緩慢調整情感基準 \(b\)，不授權改寫記憶策略。
- **明確介面契約**：與記憶模組的時間共用、歷史快照記錄、重播額度、所有權邊界都有形式化說明。
- **工程可落地**：提供完整工程數值初值、量化規則（三位小數且保持限制盒）、數值分析條件。

## 重要邊界（請先讀）

- 不建模生理喚起、激素、睡眠、晝夜節律。
- 人格演化僅限情緒傾向與情緒表現，不授權改寫記憶內容、檢索規則或策略。
- 十一軸輸出不是完整可恢復狀態，暫停／恢復需保存內部狀態。
- 工程初值為自主設定，待校準；不宣稱已符合人類。
- 記憶重播有獨立額度與劑量，不自動算新證據或新人格經驗。
